# Ocean Climate AI — Streamlit

## Files
- `app.py`: Streamlit interface; calls the trained classifier and regressor.
- `requirements.txt`: deployment dependencies.
- `ocean_climate_models.joblib`: generated by the Colab training notebook.
- `classification_results.csv`, `regression_results.csv`, `noaa_hawaii_training_data.csv`: generated by notebook.

## Run locally
1. Run the training notebook in Colab, then download the four generated files.
2. Place the files beside `app.py`.
3. Run:
   ```bash
   pip install -r requirements.txt
   python -m streamlit run app.py
   ```

## Deploy for class demo
Upload `app.py`, `requirements.txt`, the generated `.joblib`, and the three CSVs
to a GitHub repository, then deploy `app.py` on Streamlit Community Cloud.

**Security:** Only load `.joblib` files generated by your own notebook;
never load an untrusted serialized model.

**Scientific note:** This is a next-day NOAA-style alert and DHW prediction
prototype trained on Hawaiian historical observations, not a coral mortality
prediction or proven forecast for other regions.
